# 《外科醫師的一生》設計文件

日期:2026-08-09
狀態:已與作者確認核心設計,待實作

## 一、遊戲定位

輕量單頁網頁遊戲,三國志式回合制的「人生選擇器 RPG」。主角從**高中生**開始,走完(或走不完)一個外科醫師的一生。

**調性:寫實苦中帶淚。** 事件貼近真實,諷刺藏在細節裡,目標是讓圈外人也看懂外科的處境。

**諷刺主軸(四者皆有,分散在人生階段):**

1. 血汗健保與點值——開一台大刀的給付比修手機便宜
2. 醫療糾紛與防禦醫療——救人反被告,越來越不敢開刀
3. 過勞與人生失衡——青春全獻給開刀房
4. 五大皆空與人才流失——學弟妹都去醫美,留下來的人越來越苦

**最終訊息:沒有真正的完美結局。** 制度讓人無論怎麼選都有代價。

## 二、核心循環:回合制

### 序章(16-24 歲,不是回合)

開局擲天賦後,16-24 歲以**劇本化蒙太奇**快轉,玩家沒有真正的選擇:

- 16-17 歲:模擬考、志願表、親戚的「當醫生好」——鋪陳氛圍的旁白
- **18 歲:大學聯考事件(強制)**——你註定考到全國頂尖的高分。遊戲跳出「為什麼填醫學系?」的選項(想救人/家人期待/分數到了不填可惜),**但無論選哪個,結果都是醫學系**。「這個遊戲不讓你選,就像當年一樣。」
- 19-24 歲:醫學系六年蒙太奇(大體老師、國考…)
- 24 歲:通過國考,拿到**醫師執照**——「從這一刻起,你的人生才真正開始要你自己選。」

### 本篇(25 歲起):每一年 = 一回合

**真正的時間配置玩法從拿到執照後開始**:PGY(25-26)→ 住院醫師(27-31)→ 主治(32+),到 65 歲退休,或提前離場/倒下。26 歲 PGY 結束時的**選科事件**是玩家第一個真正的人生岔路:選外科繼續本篇;選別科則提早進入結局「另一條路」——**文字保持中性,不唱衰任何一方**:沒有誰的選擇比較高明,每條路都有各自要付的代價。每回合兩階段:

### ① 規劃階段(玩家主動)

分配今年的時間點數到五軸,**12 點 = 12 個月**:

| 投資軸 | 成長 | 誰在幫你打分數 |
|---|---|---|
| 臨床 | 臨床/手術技能 ↑ | 醫院考核你 |
| 教學 | 教學聲望 ↑ | 學生評鑑你 |
| 研究 | 論文點數 ↑ | 期刊審查你 |
| 家庭 | 感情/家庭進程推進 | 家人等著你 |
| 個人 | 自我 ↑、健康回補 | **沒有人——包括你自己** |

部分階段有強制配置下限(如 PGY/住院醫師時期臨床有最低月數——你沒有選擇,這也是諷刺的一部分)。

### ② 進行階段(命運回應)

時間軸逐月推進,依「時間配置 × 能力值 × 機率」觸發事件:固定劇情事件+條件觸發事件+隨機事件。關鍵事件跳出 2-3 個選項的決策。文字逐條浮現,人生重開模擬器的閱讀節奏。

## 三、天賦系統(初始能力值)

開局擲骰。**天賦是成長曲線的斜率與事件機率的修正,不是能力本身。**

| 天賦 | 初始 | 影響 |
|---|---|---|
| 學科考試能力 | **固定高** | 你就是那個很會考試的孩子,不然進不了醫學系——這是主角唯一保證的天賦 |
| 手感/學習力 | 隨機 | 臨床技能成長斜率:同樣投 4 個月,手感好的人技能飆升,手感差的人曲線平緩 |
| 研究天賦 | 隨機 | 論文產出效率 |
| 表達魅力 | 隨機 | 教學聲望成長斜率 |
| 社交能力 | 隨機 | 醫糾機率、醫美客源、感情事件成功率(見下) |
| 體質 | 隨機 | 健康衰退速率 |

### 社交能力的雙面刃(諷刺核心)

- **醫糾機率 = f(臨床能力↓ 加成,社交能力↑ 減免)**——臨床技能低,被家屬告的機率上升;但社交能力高能大幅壓低醫糾機率。**會說話比會開刀更能保護你不被告。**
- **轉醫美的成敗看社交,不看刀工**——臨床技能滿分但社交低,出去開醫美診所會沒有客人;臨床平庸但社交高,醫美反而風生水起。
- 感情事件的成功率也受社交能力修正。

## 四、屬性系統

**能力(時間投資 × 天賦斜率的產出):**

- 臨床/手術技能
- 教學聲望
- 論文點數

**代價與狀態:**

- 感情/家庭進程(見下)
- 自我(「個人」軸產出)
- 健康(「個人」軸回補)

**生存資源:**

- 存款——**與能力幾乎脫鉤**,主要由職級與制度事件決定

### 感情/家庭是進程鏈,不是數值條

**單身 → 曖昧 → 穩定交往 → 結婚 → 生子**

- 每一步需要持續的家庭時間投資才可能推進(今年沒投家庭時間,戀愛事件不會觸發)
- 疏於投資會倒退:分手、離婚事件
- **生子後家庭的「基本時間稅」上升**——孩子不因你在值班就不用陪;投不夠,觸發的不是「沒進展」,而是「孩子不認得你」這類事件

### 核心機制 1:能力與生存資源脫鉤

- 薪水由「職級 + 制度事件」決定。住院醫師薪水是死的;主治薪水看健保點值與醫院抽成——手術技能 90 分和 60 分,月薪差距極小。
- 手術技能高反而觸發:更難的轉診、更長的刀、更高的醫糾曝險。**能力的報酬是更多的工作。**
- 真正讓存款上升的路徑:減少練刀、兼醫美、或離開外科。遊戲不阻止,但「自我」與結局文字會誠實反映。

### 核心機制 2:教職系統——升等只看論文,而且要先有博士

職級:住院醫師 → 主治 → 助理教授 → 副教授 → 教授。升等門檻只看**論文點數+教學時數**,手術技能不在公式裡。卡住的不是薪水(反正都差不多),是頭銜與排刀優先權。

**博士班決策:** 要從主治升上助理教授,**必須先取得博士學位**——論文和教學時數都夠,沒有學位連送審資格都沒有。主治時期會出現「攻讀在職博士班」的決策:

- 就讀期間,每年的研究時間投資累積博士進度(進度累積到門檻才畢業),並額外消耗健康(在職進修=白天開刀晚上上課)
- 不念博士,就當一輩子主治——遊戲不評判這個選擇,但教職之路就此關閉
- 諷刺點:一雙能接血管的手、三十篇論文,表格上少一行學歷,一切免談

### 核心機制 3:健康=壽命=遊戲長度

- 健康隨年齡自然下滑;臨床/研究投資過重會加速崩壞;「個人」投資是唯一回補來源;體質天賦決定衰退速率。
- 健康見底 → 強制健康事件,可能直接死亡(過勞死結局)。**荒廢個人的玩家可能 45 歲倒在開刀房,連玩到結局的資格都沒有。**

### 核心機制 4:「自我」是結局的濾鏡

- 「自我」平常幾乎不影響遊戲進行——這正是它容易被歸零的原因:荒廢它短期毫無懲罰。
- 結局時,無論其他屬性多高,自我過低則所有結局蒙上同一層灰:
  > 「你到死的時候,始終不知道自己為什麼活得這麼累。」
- 自我夠高時,即使其他平庸,結局文字多一分和解感。

## 五、結局系統

遊戲終點:65 歲、提前離場(轉行/移民/醫美)、或健康歸零倒下。依最終屬性組合落入不同結局,例如:

- 手術技能滿、家庭歸零 →「手術室的傳說,家裡的陌生人」
- 中途轉醫美且社交高,存款滿 →「你的雷射打得又快又好」
- 中途轉醫美但社交低 →「診所的租金又漲了」
- 論文滿貫升教授、手術平庸 →「你已經很久沒進開刀房了」
- 健康歸零 →「醫者不能自醫」
- 五軸平衡但全部平庸 → 最接近「好結局」,但遊戲會告訴你:你放棄了成為傳說的機會

每個結局附**人生結算單**:總刀數、救回人數、錯過的家庭晚餐、被告次數、沒人引用的論文數…——用數字讓玩家自己品味。

「自我」濾鏡疊加在所有結局之上(見核心機制 4)。

## 六、技術架構

方案 A:免建置純 Vanilla JS 靜態專案。

```
surgeon-life/
├── index.html
├── style.css
├── src/
│   ├── engine.js    # 純邏輯:回合推進、天賦擲骰、屬性運算、事件抽取、結局判定(不碰 DOM)
│   ├── events.js    # 事件資料(各階段固定+條件+隨機事件)
│   ├── endings.js   # 結局判定表與結算單
│   └── ui.js        # DOM 渲染、時間配置介面、時間軸動畫
├── tests/           # Vitest
└── docs/
```

- ES module,瀏覽器直接開即玩,零建置。
- 部署:GitHub Pages。
- 手機優先的響應式版面(醫界同溫層以手機分享為主)。

## 七、測試策略

- **Unit test(Vitest,對 engine):** 天賦擲骰範圍、屬性成長公式(時間 × 天賦斜率)、時間配置驗證(五軸加總=12、強制下限)、醫糾機率公式(臨床↓/社交↑ 修正)、感情進程推進與倒退、健康衰退與死亡判定、升等判定、結局判定覆蓋所有分支。
- **資料完整性測試:** 每個事件/結局欄位齊全、數值合法、引用的屬性名稱存在。
- **Smoke test:** 以隨機策略自動玩完整場 N 次,確保任何配置都能走到某個結局、不會卡死或屬性爆界。

## 八、CI/CD

- ESLint + Prettier + pre-commit
- GitHub Actions:lint + test
- 依全域慣例於專案建立時設置。

## 九、明確不做(YAGNI)

- 不做存檔/雲端同步(一場約 10 分鐘,重開即重玩)
- 不做音效/美術素材(純文字+CSS)
- 不做多主角/多科別(只有外科)
- 不做後端(純靜態)
