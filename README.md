# 外科醫師的一生

一個回合制的人生經營遊戲。主角從高中生開始,走完(或走不完)一個台灣外科醫師的一生。
寫實,苦中帶淚。

水墨手繪的滿版場景、隨年齡變化的角色立繪、直排選項卡——玩起來像遊戲,不像讀小說。

## 玩法

**序章(16–24 歲):你沒有選擇。** 18 歲的聯考,無論你選什麼理由,都會進醫學系。

**本篇(25 歲起):每年一回合。** 拖曳一條分隔線,把這一年的時間按比例分給臨床、教學、
研究、家庭、個人五軸,總和 100%。各階段有制度給的臨床下限(斜線區),拖不動。

按下確認之前,畫面會先告訴你代價:健康會掉多少、醫糾機率幾 %、歸類計分離門檻還差多少、
今年會不會又缺席孩子的親子日。**看得見後果,配置才是決策,不是猜謎。**

## 這個遊戲想講的事

- 開一台八小時的大刀,實拿的錢買不起一支新手機
- 會說話比會開刀更能保護你不被告
- 升等公式裡沒有刀量這一項,從來沒有
- 「個人」這一軸荒廢了短期毫無懲罰,所以它最容易被歸零——直到你 45 歲倒在開刀房
- 沒有真正的完美結局。制度讓人無論怎麼選都有代價

## 平衡

每個策略都要付出可辨識的代價,沒有一種在所有面向都獲勝。以固定策略各跑 300 局:

| 策略     | 平均壽命 | 過勞死 | 臨床 | 歸類計分 | 家庭 | 教授率 |
| -------- | -------- | ------ | ---- | -------- | ---- | ------ |
| 全臨床   | 31 歲    | 100%   | 72   | 36       | 1    | 0%     |
| 個人拉滿 | 66 歲    | 0%     | 64   | 41       | 0    | 0%     |
| 學術路線 | 54 歲    | 75%    | 78   | 1124     | 41   | 56%    |
| 永續刀手 | 66 歲    | 0%     | 78   | 223      | 100  | 0%     |

三個關鍵機制讓「時間拉滿一軸」不再是解法:各軸的成長都有邊際遞減(個人軸最陡)、
健康上限隨年齡下降、臨床低於 25% 技能會退步。

## 開發

    npm install
    npm test          # Vitest,81 項
    npm run lint      # ESLint
    python3 -m http.server 8080   # 本機遊玩:開 http://localhost:8080

零建置:純 Vanilla JS ES modules。手機請橫向遊玩(直握會提示轉向)。

### 檔案

| 路徑                 | 職責                                     |
| -------------------- | ---------------------------------------- |
| `src/engine.js`      | 規則:回合推進、成長公式、結算、後果預告  |
| `src/events.js`      | 事件資料(含各事件對應的場景)             |
| `src/endings.js`     | 結局判定與人生結算單                     |
| `src/view.js`        | DOM 渲染:場景、立繪、HUD、文字框、選項卡 |
| `src/alloc-panel.js` | 年度配置盤(可拖曳的比例條)               |
| `src/ui.js`          | 流程串接                                 |
| `tools/`             | 美術生成管線,見 `docs/art-assets.md`     |

架構決策見 `docs/adr/`,設計文件見 `docs/superpowers/specs/`。
