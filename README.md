# 外科醫師的一生

**▶ 線上遊玩：https://odafeng.github.io/surgeon-life/**(請用電腦或手機橫向)

一個回合制的人生經營遊戲。主角從高中生開始，走完（或走不完）一個台灣外科醫師的一生。
寫實，苦中帶淚。

水墨手繪的滿版場景、隨年齡變化的角色立繪、直排選項卡——玩起來像遊戲，不像讀小說。

## 玩法

**序章（16–24 歲）：你沒有選擇。** 18 歲的聯考，無論你選什麼理由，都會進醫學系。

**本篇（25 歲起）：每年一回合，分成三步。**

一、**分時間**。拖曳一條分隔線，把這一年按比例分給臨床、教學、研究、家庭、個人五軸，
總和 100%。各階段有制度給的臨床下限（斜線區），拖不動。按下確認之前，畫面會先告訴你代價：
健康會掉多少、醫糾機率幾 %、歸類計分離門檻還差多少、今年結餘幾萬、健保點值多少。
**看得見後果，配置才是決策，不是猜謎。**

二、**花精力**。分完時間還有幾點精力可以用在具體的事情上——練刀、寫論文、投稿好期刊、
陪主任應酬、安排一趟旅行、去看身心科、兼差假日刀。精力綁在「個人」這一軸：
不留時間給自己的人，連改變現況的餘裕都沒有。

三、**接受回應**。事件依你的配置與運氣觸發，關鍵時刻要你做決定。

嫌一年一年調太慢，可以按「連續過 3／5／10 年」。快轉時會跳過分配與行動，
但需要你決定的事件一定會停下來。隨時可以存檔，標題畫面有「繼續上次的人生」。

## 內容量

278 個事件，依人生階段分佈：PGY 40、住院醫師 88、主治 154、醫美 78（跨階段的家庭事件重複計算）。
一局約 40 年、每年 2 個，所以一輪玩下來大概會遇到八十幾個，兩局不會一樣。

## 這個遊戲想講的事

- 開一台八小時的大刀，實拿的錢買不起一支新手機
- 會說話比會開刀更能保護你不被告
- 升等公式裡沒有刀量這一項，從來沒有
- 「個人」這一軸荒廢了短期毫無懲罰，所以它最容易被歸零——直到你 45 歲倒在開刀房
- 沒有真正的完美結局。制度讓人無論怎麼選都有代價

## 平衡

每個策略都要付出可辨識的代價，沒有一種在所有面向都獲勝。以固定策略各跑 300 局：

| 策略     | 平均壽命 | 過勞死 | 臨床 | 歸類計分 | 家庭 | 教授率 |
| -------- | -------- | ------ | ---- | -------- | ---- | ------ |
| 全臨床   | 31 歲    | 100%   | 72   | 36       | 1    | 0%     |
| 個人拉滿 | 66 歲    | 0%     | 64   | 41       | 0    | 0%     |
| 學術路線 | 54 歲    | 75%    | 78   | 1124     | 41   | 56%    |
| 永續刀手 | 66 歲    | 0%     | 78   | 223      | 100  | 0%     |

三個關鍵機制讓「時間拉滿一軸」不再是解法：各軸的成長都有邊際遞減（個人軸最陡）、
健康上限隨年齡下降、臨床低於 25% 技能會退步。

## 開發

    npm install
    npm test          # Vitest,81 項
    npm run lint      # ESLint
    python3 -m http.server 8080   # 本機遊玩：開 http://localhost:8080

零建置：純 Vanilla JS ES modules。手機請橫向遊玩（直握會提示轉向）。

### 檔案

| 路徑                  | 職責                                            |
| --------------------- | ----------------------------------------------- |
| `src/engine.js`       | 規則：回合推進、成長公式、結算、後果預告        |
| `src/events.js`       | 事件匯總；實際內容拆在 `src/events/` 依階段分檔 |
| `src/actions.js`      | 精力公式與 20 個回合內指令                      |
| `src/save.js`         | 存檔序列化（含亂數狀態，讀檔後序列一致）        |
| `src/endings.js`      | 結局判定與人生結算單                            |
| `src/view.js`         | DOM 渲染：場景、立繪、HUD、文字框、選項卡       |
| `src/alloc-panel.js`  | 年度配置盤（可拖曳的比例條）                    |
| `src/action-panel.js` | 行動面板                                        |
| `src/ui.js`           | 流程串接、快轉、存讀檔                          |
| `tools/fullwidth.py`  | 中文全形標點轉換與檢查（`--check`）             |
| `tools/`              | 美術生成管線，見 `docs/art-assets.md`           |

架構決策見 `docs/adr/`，設計文件見 `docs/superpowers/specs/`。
